# Centre Dentaire Le Pont — Dental Centre Website

Static Next.js website for Centre Dentaire Le Pont, a dental centre in Tangier, Morocco.
Built from the proven Dalil/Algo template (same code base, fully rebranded).

- Phone / WhatsApp: +212 666 56 54 95 (wa.me/212666565495)
- Address: Bâtiment 02, Porte 01, Route Principale, Rue Florencia, Tanger 90000 (Résidence Florencia)
- Google rating shown in the hero: 5.0 (from the centre's Google listing)
- Languages: Arabic (default, RTL), French, English
- Booking form opens WhatsApp with the form details prefilled in the selected language
- Chatbot: 100% local FAQ layer in French, Arabic and English (no API, no server).
  Prices and medical questions are always deflected to WhatsApp, by construction.
- Logo: original Le Pont mark (navy tooth under a sky-blue bridge arch) generated for this centre.
- Sections removed vs the template: Social (the centre has no public social profiles) and
  Before/After (the template's case photos belong to another clinic's patients; the section
  can be re-added with Le Pont's own cases once the clinic supplies them).
- Placeholders the clinic must still confirm: opening hours (shown as Lun–Sam 09:00–19:00),
  hero stats, testimonials (generic sample texts — NOT real patient quotes yet).
- Build: npm install, then npm run build (static export in out/).
